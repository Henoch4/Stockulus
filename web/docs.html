Stockulus ships as an off-chain Python agent plus two on-chain Solana programs. Everything here matches what's actually deployed — no invented steps.

Prerequisites

Three toolchains, one for each layer of the stack: Rust/Anchor for the on-chain programs, Node for the Meteora swap wrapper, Python for the agent itself.

# Rust + Anchor
cargo install --git https://github.com/coral-xyz/anchor avm --locked --force

# Node.js
npm i -g pnpm

# Python 3.11+
pip install anchorpy solders httpx hmmlearn pyyaml python-dotenv

Deploy on-chain

Build the TypeScript swap wrapper and both Anchor programs, then deploy to devnet. This step produces the two program IDs you'll put in .env next.

# 1. Build the TypeScript SDK wrapper
cd app/ts && pnpm install && pnpm run build

# 2. Build the Anchor programs
cd programs/trade_audit_trail && cargo build-sbf
cd programs/trading_vault && cargo build-sbf

# 3. Deploy to devnet
anchor deploy --provider.cluster devnet

Environment variables

Copy .env.example to .env and fill these in. Anything marked required blocks the agent from starting; everything else degrades gracefully — a missing Clawpump key just skips the launch demo, for example.

VariableWhat it's for
RPC_URL requiredSolana RPC endpoint. Defaults to public devnet.
ANCHOR_PROGRAM_ID requiredDeployed address of the audit-trail program.
VAULT_PROGRAM_IDDeployed address of the vault program.
AGENT_KEYPAIR_PATH requiredPath to the agent's Solana keypair file. Devnet throwaway — never reuse on mainnet.
CLAWPUMP_API_KEY optionalEnables the agent-launch demo. Missing = that part is skipped, rest still runs.
NANSEN_API_KEY optionalOn-chain flow signal. Missing = that signal stays neutral.
PYTH_API_KEY optionalLive SOL/USD for swap sizing (keyed Hermes). Missing = SOL_PRICE_USD estimate is used, no network call.
BITGET_DIVERGENCE_BPSMax xStocks↔Bitget spot spread before the asset is blocked (default 100bps). The Bitget feed itself needs no key.
RISK_STATE_PATHWhere daily loss/trade counters persist across restarts.
QUOTE_MINT / QUOTE_DECIMALSQuote asset for the DBC pools — wSOL on devnet, USDC on mainnet.
DBC_POOL_AAPLX / TSLAX / NVDAXPool address for each tokenized stock, from create_pool.js.

Run the agent

With .env filled in and a funded devnet keypair, start the agent. It defaults to dry run — decisions and the risk gate all run for real, but nothing gets swapped or logged on-chain until you explicitly turn that off.

# from the repo root
export RPC_URL=https://api.devnet.solana.com
export ANCHOR_PROGRAM_ID=<deployed_program_id>
export AGENT_KEYPAIR_PATH=./agent_keypair.json

python -m agent

To open the desk with live numbers, serve the site plus the agent's metrics endpoints (read-only — no trades, no transactions):

# from the repo root — desk at http://127.0.0.1:8000/
python -m app.agent.serve

To confirm everything's wired correctly before running for real, the repo includes a smoke test that runs a full dry-run cycle against fake price data:

python scripts/test_wiring.py
